Update MHCO content

mhco.org blocks automated access from Chat MHC's servers, so new MHCO articles and the associate members list come in through your own browser: a bookmark button reads them while you're logged in to mhco.org, saves them as a file, and you drop that file into GitHub. Oregon laws still update on their own every month.

One-time setup (Chrome or Edge)

  1. Show your bookmarks bar: Ctrl+Shift+B (on a Mac: ⌘+Shift+B).
  2. Drag this button onto the bookmarks bar: Grab MHCO updates

    The button couldn't be prepared — reload this page and try again.

Each time you want to update

  1. Go to mhco.org and log in.
  2. Click Grab MHCO updates in your bookmarks bar and choose Newest (about 2 minutes). Choose Everything once in a while (about 15 minutes) to pick up edited or removed articles. Keep the tab open while it works.
  3. When it says Saved!, click Open upload page, drag the downloaded mhco-export-….json.gz file into it, and click Commit changes.
  4. Done. Chat MHC updates itself in about 5 minutes. To watch, open the repository's Actions tab on GitHub; the run's summary lists what was added.

If something goes wrong

  • Clicking the bookmark does nothing: make sure you're on an mhco.org page, then click it once more. If you dragged it before this page was updated, drag the new button again.
  • "mhco.org asked us to slow down": it waits and retries by itself. If it stops early, upload the file anyway; whatever it got is used and nothing is lost.
  • Nothing changed in Chat MHC: there may simply be no new articles. The GitHub run's summary says what happened.
  • Upload only the file you just saved. A file older than one already uploaded is skipped, so it can't undo newer content.
  • Not logged in? The file then only adds new articles; log in and grab again to refresh or tidy up existing ones.
